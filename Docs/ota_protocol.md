# OTA 协议说明（源码阅读稿，待与上位机核对）

## 源码定义的报文

```text
+--------+--------+--------------------+--------------------+-----------------+
| 0xAA   | 0x55   | BIN 长度 uint32 LE | CRC32 uint32 LE    | BIN 数据        |
+--------+--------+--------------------+--------------------+-----------------+
```

- 帧头：`AA 55`。
- BIN 长度：4 字节小端，Bootloader 检查非零且不超过 `APP_MAX_SIZE`。
- CRC32：4 字节小端；源码实现使用反射多项式 `0xEDB88320`，初值 `0xFFFFFFFF`，结束取反。
- 数据：源码按最多 1024 字节一块接收，每块写入后回复 `BOOT> ACK
`。
- 相关文本响应包括 `BOOT> GO`、`BOOT> LEN ERR`、`BOOT> RX TO`、`BOOT> CRC FAIL`、`BOOT> OTA OK, jump`。

## 安全说明

CRC32 只能检测部分传输错误，不是密码学签名。若需防止恶意固件，应另行设计固件签名验证、可信公钥管理及版本回滚策略。
