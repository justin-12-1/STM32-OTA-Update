# Flash 分区说明（需实测核对）

> 本文先记录源码中当前配置，不等同于已验证的芯片物理布局。修改前请查阅目标 MCU 数据手册/参考手册，并核对实际料号。

## 源码当前配置

| 区域 | 起始地址 | 长度/终止地址 | 来源 |
|---|---:|---:|---|
| Bootloader | `0x08000000` | 链接脚本长度 `0x5C00`，结束边界 `0x08005C00` | `Bootloader/STM32F103C8TX_FLASH.ld` |
| 升级标志页 | `0x08005C00` | 源码按 1 页擦除；标志字位于 `0x08005FF0` | `Bootloader/Core/Src/main.c`、APP `myflash` 模块 |
| APP | `0x08006000` | 链接脚本长度 38 KiB，理论结束边界 `0x0800F800` | `ChaoShengjc1111/STM32F103C8TX_FLASH.ld` |
| APP 最大 BIN 长度 | — | `0x9800`（38 KiB） | Bootloader `APP_MAX_SIZE` |

## 必须核对

- [ ] 实际 MCU 型号与 Flash 容量（不可仅凭工程名判断）。
- [ ] Flash 页大小，以及 `Boot_ErasePage()` 对每个数据块实际擦除的页数。
- [ ] APP 链接脚本长度、Bootloader 可执行文件最大占用与标志页是否重叠。
- [ ] `APP_ADDR`、APP 向量表偏移、链接脚本 ORIGIN 三者一致。
- [ ] APP BIN 最大长度不越过物理 Flash 末端。
- [ ] 上位机生成的 BIN 不包含错误偏移或不适用于该分区的地址内容。
- [ ] 在可恢复的测试板上验证断电/复位后的行为。
