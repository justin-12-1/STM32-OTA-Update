# STM32 OTA 固件更新系统

基于 STM32 的 Bootloader 与 OTA 固件更新项目，围绕嵌入式固件更新、无线通信及应用程序启动管理开展实践。

## 项目简介

本项目包含 STM32 Bootloader 和应用程序相关工程，并整理了项目文档与图片资料。项目旨在探索通过 ESP8266 实现无线通信，以及 STM32 固件更新相关功能。

具体功能以当前代码实现为准。
